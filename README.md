# 🐍 Retro Snake

> A colorful, cute retro snake game built with **HTML, CSS & JavaScript** — no frameworks, no dependencies. Just open the file in a browser and play!

## 🎮 How to Play

Open `index.html` in any modern browser.

| Control | Action |
|---------|--------|
| `↑ ↓ ← →` or `W A S D` | Move the snake |
| `SPACE` | Pause / resume |
| `M` | Mute / unmute sound |

> ⚠️ **Hitting the walls = game over!** So do the math before you turn.

## ✨ Features

- 🌈 Rainbow-gradient snake with **uniform circle segments**
- 👀 Cute kawaii eyes that look in the direction you're moving
- 🍎 Glossy, pulsing apple food with a leaf
- 🔊 Sound effects generated with the **Web Audio API** (eat / level-up / death)
- 📈 Speed levels up every 5 apples
- 🏆 High score saved in `localStorage`
- 📱 On-screen D-pad for touch devices

## 🛠️ Tech

- Canvas 2D rendering with per-frame interpolation (smooth movement)
- `requestAnimationFrame` game loop
- Web Audio API for retro-style SFX
